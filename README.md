================================================================================
                    FACE RECOGNITION SYSTEM
              Система распознавания лиц на Python + PyQt5
================================================================================

ОПИСАНИЕ
--------------------------------------------------------------------------------
Проект для распознавания лиц с графическим интерфейсом на PyQt5 и
использованием библиотеки face_recognition.

Система позволяет:
  - Добавлять новых пользователей (сбор фотографий с веб-камеры)
  - Обучать нейросеть на основе собранных фотографий
  - Распознавать лица в реальном времени через веб-камеру
  - Просматривать и удалять фотографии пользователей


СТРУКТУРА ПРОЕКТА
--------------------------------------------------------------------------------
face/
├── visual.py          # Главное окно приложения (GUI на PyQt5)
├── recognition.py     # Распознавание лиц в реальном времени
├── encod.py           # Обучение нейросети (создание эмбеддингов)
├── encod.txt          # Файл с эмбеддингами обученных пользователей
├── photo.py           # Сбор фотографий нового пользователя
├── rem_photo.py       # GUI для управления фотографиями
├── read_photo.py      # Чтение и вывод эмбеддингов из encod.txt
├── haar.py            # Альтернативный метод (Haar + Sobel)
├── test2.py           # Экспериментальный метод (LBP / ORB)
├── camera.py          # Тест камеры с отображением FPS
├── start.py           # Консольная версия меню
└── faces/             # Папка с фотографиями пользователей


УСТАНОВКА
--------------------------------------------------------------------------------
1) Клонирование репозитория:

   git clone <url-репозитория>
   cd face


2) Создание виртуального окружения (рекомендуется):

   python -m venv faceenv

   Windows:
     faceenv\Scripts\activate

   Linux/Mac:
     source faceenv/bin/activate


3) Установка зависимостей:

   pip install opencv-python
   pip install face_recognition
   pip install PyQt5
   pip install numpy
   pip install scikit-image

   ВНИМАНИЕ: Для face_recognition требуется dlib.
   На Windows может потребоваться установка CMake и Visual Studio Build Tools.


ИСПОЛЬЗОВАНИЕ
--------------------------------------------------------------------------------
Запуск GUI-версии:

   python visual.py


Запуск консольной версии:

   python start.py


Меню консольной версии:
   1. Добавить пользователя — введите имя, будет сделано 10 снимков с камеры
   2. Синхронизировать распознавание — обучение на новых фото (encod.py)
   3. Распознавание — запуск распознавания в реальном времени
   4. Выйти


МОДУЛИ
--------------------------------------------------------------------------------
visual.py        - Главное окно с кнопками управления
photo.py         - Захват 10 фото с камеры, сохранение в faces/Имя#N.jpg
encod.py         - Генерация 128-мерных эмбеддингов и запись в encod.txt
recognition.py   - Распознавание через face_recognition, порог расстояния 0.5
rem_photo.py     - Просмотр/удаление фото, группировка по имени
read_photo.py    - Утилита для чтения encod.txt
haar.py          - Альтернатива: Haar Cascade + Sobel-гистограмма
test2.py         - Экспериментальный метод (LBP или ORB)
camera.py        - Проверка камеры, отображение FPS


ФОРМАТ ФАЙЛА encod.txt
--------------------------------------------------------------------------------
Каждая строка содержит имя файла и 128 чисел (эмбеддинг лица):

   Имя#Номер.jpg:[0.123 -0.456 ... 0.789]


ТРЕБОВАНИЯ К КАМЕРЕ
--------------------------------------------------------------------------------
  - Индекс камеры указывается в коде: cv2.VideoCapture(0) или (1)
  - Рекомендуется хорошее освещение
  - Расстояние до лица — 50–80 см


ВОЗМОЖНЫЕ ПРОБЛЕМЫ
--------------------------------------------------------------------------------
Проблема                     | Решение
-----------------------------|--------------------------------------------------
encod.txt не найден          | Сначала добавьте пользователя и запустите обучение
Камера не открывается        | Измените индекс в cv2.VideoCapture(N)
dlib не устанавливается      | pip install cmake, затем pip install dlib
Низкая точность              | Соберите больше фото (10+ на человека),
                             | улучшите освещение


ПРИМЕЧАНИЯ
--------------------------------------------------------------------------------
  - Порог распознавания: 0.5 (меньше = строже)
  - В recognition.py обрабатывается каждый 10-й кадр (k=10)
    для повышения производительности
  - Размер эмбеддинга: 128 чисел (face_recognition)
